# StudyPilot

StudyPilot 是一个面向大学生的 AI 课程学习助手。用户可以上传文字版 PDF，进行带页码引用的资料问答，生成测验，并根据错题查看薄弱知识点。

当前阶段：项目骨架。

## 技术栈

- React 19 + TypeScript + Vite
- FastAPI + Pydantic + SQLAlchemy
- PostgreSQL 16 + pgvector
- 阿里云百炼 `qwen-plus` 与 `text-embedding-v4`
